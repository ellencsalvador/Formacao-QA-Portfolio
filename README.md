# 🧪 Portfólio de Qualidade de Software (QA) - Ellen Salvador

Este repositório centraliza minha jornada de aprendizado e prática em QA, reunindo desafios, automações e documentações técnicas desenvolvidas na Formação do **Instituto Joga Junto** em parceria com o **Ilhabela Tech**.

## 🛠️ Stack Tecnológica
- **Linguagens:** Python e JavaScript.
- **Automação:** Selenium WebDriver.
- **Testes de API:** Postman.
- **Metodologia:** BDD (Behavior Driven Development) com Gherkin.
- **Frameworks:** Padrão Page Object Model (POM).

## 📁 Organização do Repositório
- **/Aulas-Basico**: Fundamentos de testes manuais, planos de teste e relatórios de bugs.
- **/Automacao-Selenium**: Scripts de automação para e-commerce e fluxos críticos.
- **/Testes-API**: Coleções do Postman para validação de endpoints.
- **/Documentacao-BDD**: Escrita de cenários em Gherkin.

## 🎯 Principais Conquistas
- Implementação de testes automatizados com foco em regressão.
- Criação de planos de teste detalhados para aplicações web e mobile.
- Colaboração em squads para resolução de problemas coletivos e entregas ágeis.
